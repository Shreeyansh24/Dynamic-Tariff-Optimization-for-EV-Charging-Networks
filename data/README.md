# Data

| Directory | Contents |
|-----------|----------|
| `raw/` | Source ACN session JSON and UrbanEV CSVs (downloaded automatically) |
| `processed/` | Intermediate harmonized datasets (generated by pipeline) |
| `outputs/` | Agent forecasts, pricing decisions, metrics, and charts |

## Download

```bash
python scripts/download_data.py
```

## Regenerate

```bash
python scripts/run_pipeline.py
```

Large CSVs and model artifacts are excluded from version control. Run the commands above to reproduce them locally.
